# A KI PRI SA YÉ — Pack "Darkness Pro" (React + Vite + Tailwind)

## Installation
```bash
npm i
npm run dev    # dev
npm run build  # prod
```

## Déploiement Firebase Hosting
Dans le dossier, lance :
```bash
npm run build
firebase deploy
```

## Points clés
- Thème sombre moderne ("Darkness Pro")
- TailwindCSS + composants simples
- Sélecteur de langue (FR / Kreyòl / ES)
- PWA manifest + icônes 192/512
- Liens vers /chat, /ocr, /comparateur (à brancher sur tes routes existantes)
