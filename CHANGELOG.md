## [0.1.0] - 2025-01-10

### Added

- Initial release of A KI PRI SA YÉ application
- Product search and comparison by EAN code
- Price tracking across DROM-COM territories
- PWA support with offline functionality
- Firebase integration for data storage
- Territory selector for 12 DROM-COM regions
- News widget with dynamic updates
- Interactive map for store locations
- Responsive design with mobile-first approach
- Service worker for offline support
- Upload and OCR scanning of receipts
- Basic API endpoints for prices, news, and contact
- Security rules for Firestore database
- Automated smoke tests
