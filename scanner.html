📷 Scanner de code-barres

Comment utiliser :
1. Cliquez sur "Démarrer la caméra" pour scanner en direct
2. Positionnez le code-barres dans le cadre bleu
3. Le code sera détecté automatiquement
4. Vous serez redirigé vers le comparateur de prix

Formats supportés : EAN-8, EAN-13, UPC-A, UPC-E
