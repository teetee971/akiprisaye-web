# 📚 Documentation utilisateur - A KI PRI SA YÉ

## Vue d'ensemble

A KI PRI SA YÉ est une application web complète de comparaison de prix pour les territoires d'Outre-Mer (DROM-COM). Cette documentation décrit toutes les fonctionnalités disponibles et comment les utiliser.

## 🚀 Fonctionnalités principales

### 🔍 Comparaison de prix
- Recherche de produits par nom, code-barres ou catégorie
- Comparaison automatique des prix entre enseignes
- Filtrage par zone géographique (Guadeloupe, Martinique, Guyane, etc.)
- Affichage des prix au kg/litre pour faciliter la comparaison

### 📱 Application mobile (PWA)
- Installation possible sur mobile et ordinateur
- Fonctionnement hors ligne
- Notifications push pour les bonnes affaires
- Interface optimisée pour mobile

### 📊 Export des données
- Export Excel (.xlsx) des comparaisons
- Export PDF pour impression
- Données incluant prix, enseignes, dates et zones

### 💡 Suggestions locales
- Recommandations basées sur votre géolocalisation
- Suggestions saisonnières selon les produits disponibles
- Magasins à proximité avec distances
- Bonnes affaires du moment

### 📰 Actualités économiques
- Flux d'actualités filtrées par territoire
- Articles sur la vie chère et la consommation
- Mise à jour automatique

## 📖 Guide d'utilisation

### Installation de l'application (PWA)

1. **Sur mobile (Android/iOS):**
   - Visitez https://akiprisaye.pages.dev
   - Appuyez sur le bouton "Ajouter à l'écran d'accueil"
   - L'icône apparaîtra sur votre écran d'accueil

2. **Sur ordinateur (Chrome/Edge):**
   - Visitez le site web
   - Cliquez sur l'icône d'installation dans la barre d'adresse
   - Confirmez l'installation

### Recherche de produits

1. **Recherche simple:**
   - Saisissez le nom du produit dans la barre de recherche
   - Sélectionnez votre territoire
   - Cliquez sur "Rechercher"

2. **Recherche avancée:**
   - Utilisez les filtres par catégorie
   - Précisez la taille/poids du produit
   - Filtrez par enseigne

3. **Scan de code-barres:**
   - Cliquez sur l'icône de scan
   - Autorisez l'accès à la caméra
   - Pointez vers le code-barres

### Comparaison et export

1. **Comparer les prix:**
   - Les résultats s'affichent automatiquement triés par prix
   - Cliquez sur une enseigne pour voir les détails
   - Utilisez la carte pour localiser les magasins

2. **Exporter les résultats:**
   - Cliquez sur le bouton "📊 Excel" ou "📄 PDF"
   - Le fichier se télécharge automatiquement
   - Format : `comparaison_prix_YYYY-MM-DD.xlsx/pdf`

### Utilisation des suggestions

1. **Activer les suggestions:**
   - Autorisez la géolocalisation
   - L'icône "💡" apparaît en bas à gauche
   - Cliquez pour voir les suggestions

2. **Types de suggestions:**
   - **Historique :** Basé sur vos recherches précédentes
   - **Saisonnières :** Produits de saison disponibles
   - **Proximité :** Magasins près de vous
   - **Économies :** Bonnes affaires du moment

### Navigation du site

- **Actualités** : News économiques par territoire

## 🔧 Dépannage

### Problèmes courants

**L'application ne se charge pas :**
- Vérifiez votre connexion internet
- Videz le cache du navigateur
- Réessayez en mode navigation privée

**Les prix ne s'affichent pas :**
- Vérifiez la sélection du territoire
- Essayez avec un autre produit
- Contactez le support si le problème persiste

**Problème de géolocalisation :**
- Autorisez l'accès à la localisation
- Vérifiez les paramètres de confidentialité
- Sélectionnez manuellement votre territoire

**Export qui ne fonctionne pas :**
- Autorisez les téléchargements
- Vérifiez l'espace disque disponible
- Essayez un autre navigateur
